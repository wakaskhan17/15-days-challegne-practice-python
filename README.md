# AI Career Assistant

AI Career Assistant is a learning project that will grow into an
interactive tool for career planning and job-search support.

## Day 1 setup

This project uses a virtual environment so its Python packages and
versions remain isolated from other projects. The dependencies are
recorded in requirements.txt so the environment can be recreated.

## Run the project

```powershell
.\.venv\Scripts\Activate.ps1
python -m assistant.main
```
